# Privacy and sovereignty

Workspace cloud execution defaults to off. Cloud advising requires both server enablement and organization consent. Demo runs use the approved list of server-configured local models for advisories and model-lab tasks. The deterministic simulation and ranking run on the backend. Agents send the permitted aggregate scenario category, simulation evidence, and strategy scores to model providers. User prompts, sensor coordinates, member records, and provider credentials are kept out of advisory payloads.

Local operators can use the packaged Debrecen basemap and a local provider. Selecting an online basemap sends ordinary tile requests to the basemap host. Configure deployment-specific retention and access policies for audit records, session data, and uploaded content.
