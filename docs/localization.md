# Localization

The chooser and profile settings support English, French, and Bambara. The preference persists between the workspace and public pages. Interface catalogs in `frontend/src/i18n` translate authored navigation, actions, status labels, and form copy. Text supplied by operators, data providers, or model outputs retains its source language. Versioned archival documents carry their report language.

Review Bambara terminology with fluent operators in the intended city before deploying it for field use.
