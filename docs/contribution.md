# Contributing

Keep scenario validation and simulation code in the backend. Add provider transport through the gateway and expose new map data as GeoJSON. Preserve demonstration labeling when adding fixtures. Use structured agent evidence and ensure scenarios with the same input and seed remain deterministic.

Run Ruff formatting and linting in the backend, and lint, typecheck, and test the frontend. Add focused coverage for behavior changes. Keep credentials, uploaded datasets, and local databases outside version control.
