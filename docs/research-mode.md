# Research mode

Open **Research** and create a named experiment for the selected city and workspace. Add a scenario variant from a preset, or duplicate a saved variant and change one input. Select a seed, specialist agents, and an optional comparison provider. Keep the same seed and scenario start time when testing a single change. Model text may vary across identical calls.

The experiment compares completed runs at the same 30-minute point. Follow a run title to review its full timeline, model advisories, and decision trace. Archive a finished experiment to keep it read-only until restored. Its JSON export groups scenario variants with the retained runs, seeds, input fingerprints, scoring weights, frames, advisories, and audit evidence. Individual report CSVs contain per-strategy time series. Retain copies of external city datasets and export runs before your configured retention period ends.
